# Audit keamanan UangKu, 25 November 2026

**Keputusan saat audit: tunda rilis untuk data keuangan nyata.** Saat diperiksa, ada celah isolasi rekonsiliasi antar-akun, pencabutan akses yang tidak efektif, dan risiko pembatasan login pada konfigurasi Compose. Tidak ada bukti insiden atau kebocoran produksi dari audit ini. Tabel mencatat kondisi sebelum perbaikan; status terbaru ada di bagian terakhir.

Lingkup: worktree lokal dengan basis `54bf7b9`, termasuk perubahan yang belum di-commit. Bukti di bawah berasal dari inspeksi kode, konfigurasi, lockfile, dan tes regresi yang sudah tersedia. Tidak ada eksploitasi, pengujian beban, akses data pengguna, atau pengujian terhadap layanan produksi.

## Kerahasiaan dan ketersediaan

| ID | Prioritas | Bukti dan tindakan |
| --- | --- | --- |
| SEC-05 | Tinggi jika builder atau cache dibagikan | **Berkas lingkungan lokal masuk ke tahap build Docker.** Worktree berisi `apps/api/.env`; tidak ditemukan `.dockerignore` yang berlaku. Dockerfile menyalin seluruh direktori API ke builder. Ini memperluas akses ke isi berkas ke builder dan berpotensi cache-nya, **bukan** bukti `.env` masuk image final atau berisi kredensial produksi. Gunakan daftar berkas yang diperlukan atau `.dockerignore` untuk rahasia, unggahan, dan artefak lokal. Tinjau akses ke cache build lama sebelum memutuskan rotasi. [Dockerfile](../apps/api/Dockerfile#L14-L27). |
| SEC-06 | Sedang | **Cadangan impor dapat tertinggal setelah penghapusan akun.** `.ukbak` adalah JSON tanpa enkripsi. Pemilih dokumen membuat salinan dalam cache `DocumentPicker`; alur pemulihan tidak menghapus salinan tersebut. Penghapusan akun hanya membersihkan direktori milik pengguna dan pola ekspor lama, bukan salinan impor. Hapus hanya salinan sementara yang dibuat aplikasi segera setelah dibaca, termasuk saat batal/gagal, bukan dokumen asli; beri peringatan tentang isi cadangan. [Format cadangan](../apps/mobile/src/db/backup.ts#L21-L31), [impor](../apps/mobile/app/%28tabs%29/settings.tsx#L265-L291), [pembersihan](../apps/mobile/src/services/exportFiles.ts#L26-L32). |
| SEC-07 | Sedang, akses fisik | **Batas percobaan PIN hilang saat proses aplikasi berhenti.** Penghitung/jeda hanya ada di state React. Tidak ada kewajiban login ulang setelah sepuluh kegagalan. Secure Store melindungi nilai saat tersimpan, tetapi aplikasi menyimpan dan membandingkan PIN asli, bukan verifier seperti yang disyaratkan PRD. Simpan verifier bersalt, penghitung, dan waktu akhir jeda secara persisten; uji pemulihan dan restart pada perangkat. [Penghitung dan verifikasi](../apps/mobile/app/_layout.tsx#L83-L113), [penyimpanan PIN](../apps/mobile/app/security/index.tsx#L200-L209), [persyaratan](../prd.md#L3303-L3308). |
| SEC-08 | Sedang | **Unggahan struk tidak memiliki kuota total per akun.** Ada batas 5 MB per berkas, tetapi aplikasi baru memeriksanya setelah mendekode seluruh string Base64. Tidak ditemukan batas total penyimpanan atau laju unggah per pemilik. Akun terautentikasi dapat menghabiskan ruang atau menambah biaya bagi pengguna lain. Batasi ukuran di ingress sebelum dekode dan terapkan kuota byte/jumlah secara atomik. ## Dependensi

Pencocokan versi pada `bun.lock` dengan basis advisori npm menemukan **27 pasangan paket-advisori pada 7 paket**, dari 702 pasangan nama-versi (626 nama paket publik). Yang diperiksa adalah versi terkunci, bukan bukti bahwa 27 celah bisa digunakan terhadap UangKu.

- API menggunakan `drizzle-orm@0.38.4`. [GHSA-gpj5-g38j-94v9](https://github.com/advisories/GHSA-gpj5-g38j-94v9) mencantumkan perbaikan di `0.45.2` untuk jalur stabil. Audit ini tidak menetapkan bahwa input pengguna mengendalikan identifier SQL di aplikasi.
- Kontrak API menggunakan `zod@3.25.76`. [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5) terkait konsumsi memori pada validasi koleksi; versi perbaikan yang dilaporkan adalah `4.6.6`. Rencanakan migrasi lintas major dengan tes kontrak dan batas ukuran masukan sebelum validasi.
- Lima paket lain: `node-forge`, `esbuild`, `glob`, `minimatch`, dan `uuid`. Contohnya, `node-forge` masuk melalui alat penandatanganan Expo. Pisahkan paparan build/CI dari kode yang benar-benar dikirim ke perangkat. Pemindaian ini tidak mencakup citra OS, runtime Bun, atau dependensi native di luar lockfile npm.

## Yang sudah diverifikasi

**14 tes terkait autentikasi, struk, dan penyimpanan mobile lulus; 0 gagal.** Tes memakai PostgreSQL sementara, penyimpanan struk sementara, serta SQLite di memori. Kontrol positif termasuk penolakan login tanpa kredensial yang benar, peningkatan hash lama ke Argon2id setelah login sah, dan penolakan pembacaan struk tanpa sesi atau oleh akun lain. Tes hijau ini tidak menguji seluruh temuan di atas.

Tidak ada pengujian iOS/Android fisik, inspeksi konfigurasi reverse proxy/TLS yang terpasang, pemeriksaan bucket atau cache builder produksi, ataupun bukti bahwa token atau berkas pengguna pernah diambil. Rekomendasi rilis didasarkan pada perilaku kode dan dampaknya jika prasyarat terpenuhi.

## Tindak lanjut

- **SEC-01, SEC-04:** kontrak membedakan tiga aksi rekonsiliasi. PostgreSQL memeriksa pemilik saat menautkan transaksi dan mencegah dua mutasi memverifikasi transaksi yang sama. Kode patungan kini sekali pakai dan berkedaluwarsa. Mencabut anggota juga membatalkan undangan aktif tanpa menghapus riwayat setoran.
- **SEC-02, SEC-03:** sesi disimpan dan dicabut per perangkat; server memeriksa kata sandi lagi sebelum menghapus akun. Logout offline tidak diklaim sebagai pencabutan server. Pembatas login memakai IP peer atau proxy tepercaya dan penghitung per akun di PostgreSQL.
- **SEC-05, SEC-06:** konteks Docker menggunakan daftar berkas yang diizinkan. Pemulihan `.ukbak` membersihkan salinan pemilih dokumen setelah dibaca, sebelum konfirmasi pengguna, termasuk jika pembacaan gagal. Dokumen sumber tidak dihapus. Ini tidak menghapus cache builder historis atau menjamin pembersihan jika OS menghentikan proses di tengah pembacaan.
- **SEC-07, SEC-08:** PIN lama dimigrasikan ke verifier bersalt di Secure Store. Jeda dan jumlah kegagalan bertahan lintas proses; setelah sepuluh kegagalan dibutuhkan login ulang (verifikasi OS untuk tamu) dan PIN baru. API membatasi ukuran request sebelum dekode serta jumlah dan ukuran total struk. Sisa kuota diperiksa sambil mengunci baris pemilik agar dua unggahan bersamaan tidak memakai slot terakhir.
- **Dependensi:** Drizzle ORM `0.45.4`, Zod langsung `4.6.7`, dan `node-forge` `1.4.4`. `bun audit` masih melaporkan **5 advisori transitif**: `esbuild` dari alat migrasi, `glob` dan `minimatch` dari Expo, `uuid` dari alat tunnel Expo, serta Zod 3 dari Expo CLI dan dependensi dokumentasi API. Dependensi induk meminta versi mayor lama; tidak dipaksa dengan override lintas major. Jangan publikasikan server pengembangan atau tunnel untuk data nyata.

Verifikasi: 116 tes lulus, tanpa kegagalan, pada PostgreSQL sementara dan SQLite di memori. Typecheck API, contracts dan mobile, build API/migrator, ekspor Expo iOS/Android, dan validasi konfigurasi Compose lulus. Belum ada verifikasi perangkat fisik, bucket S3/R2 nyata, proxy produksi, atau cache build lama. Lihat [langkah pembaruan](../README.md#pembaruan-keamanan-migrasi-0006) sebelum rollout.
